# FotoBuddy

Android-App für funktionale Fotos: erst den Zweck tippen, dann fotografieren, filmen oder scannen. Die Datei landet mit Datum im Namen sofort im passenden Ordner, nicht zwischen den privaten Fotos in der Galerie.

- Kacheln je Kategorie (z. B. Dokument, Zählerstand, Essen, Gewicht), frei anlegbar
- Foto und Video über die eingebaute Kamera, Scan als PDF mit Randerkennung
- Ziel: neuer Ordner (versteckt vor Galerie und Google Fotos) oder ein bestehendes Album
- Ordner-Knopf je Kachel, Kacheln auf den Startbildschirm heften
- Keine Werbung, kein Konto, keine Cloud: alles bleibt auf dem Handy

## Installieren

**Direkt:** [FotoBuddy.apk herunterladen](https://github.com/KoelnThanh/fotobuddy-releases/releases/latest/download/FotoBuddy.apk) (immer die neueste Version), öffnen und „Installation aus dieser Quelle erlauben“ bestätigen.

**Mit automatischen Updates:** [Obtainium](https://github.com/ImranR98/Obtainium) installieren, dort „App hinzufügen“ und diese Adresse eintragen:

```
https://github.com/KoelnThanh/fotobuddy-releases
```

Beim ersten Start fragt die App nach „Zugriff auf alle Dateien“. Den braucht sie, um direkt in die gewählten Ordner zu schreiben.

Voraussetzung: Android 11 oder neuer.
